# Specification

Single source of truth for the queue-theory repository. Everything else
(README files, `AGENTS.md`, `llms.txt`, the website) must agree with these
files; when they disagree, fix them to match the spec, or change the spec first.

| File | Governs |
|---|---|
| [repository.md](repository.md) | Layout, file conventions, delivery (commit, push, publish) |
| [locales.md](locales.md) | Locale codes, translation workflow, locale list |
| [website.md](website.md) | The SvelteKit site: build, generated files, publishing |
