# Website

`queue-theory.github.io/`: SvelteKit 3 with `@sveltejs/adapter-static`, fully
prerendered, styled with the Lily Design System. Live at
https://queue-theory.github.io/.

## URL scheme

| URL | Page |
|---|---|
| `/` | Language router: reads `navigator.languages` and replaces itself with the best locale route (`routeForLanguages()` in `src/lib/locales.js`), else `/en-001/` |
| `/<locale>/` | The locale's landing page: its translated README |
| `/<locale>/?<query>` | Search results within that locale only |

There is no `/en/` site; English is `/en-001/`.

## Landing page

`landingOf()` in `src/lib/server/locale-pages.js` renders the locale's
`index.md`:

- **Hero**: the `#` title, a one-sentence subheadline and the "Translations: "
  label (hand-authored in `src/lib/data/hero.js`), the first paragraph, and
  the endonym of every `*-001` locale as a link.
- **Six cards**: H2 sections 1, 3, 4, 5, 6 and 7 (introduction, notation, queue
  math, activity tracking, service metrics, queue of queues), each with its
  first prose paragraph, linking to the section anchor.
- **Body**: the rest of the README, rendered with `marked`. Heading ids use
  the same slug rules as GitHub, so the README's contents list works. Relative
  links resolve to the file on GitHub.

## Search

`static/search/<locale>.json` holds one record per H2 section, with the
section anchor as its URL. The header's search picker submits to
`/<locale>/?<query>`.

## Generated vs hand-authored

| Path | Kind |
|---|---|
| `src/content/locales/<code>/index.md`, `src/lib/locale-pages.json` | Generated by `scripts/sync-locales.mjs` from `../locales/` |
| `static/images/*.svg` | Copied by `make content` from the root `static/images/`, the source of truth |
| `static/search/<code>.json` | Generated by `scripts/generate-search-index.mjs` |
| `static/sitemap.xml` | Generated by `scripts/generate-sitemap.mjs` |
| `static/llms.txt`, `static/llms.json` | Generated by `scripts/generate-llms.mjs` |
| `build/<locale>/sitemap.xml` | Generated at build time by `scripts/build-locale-sitemaps.mjs` |
| `static/themes/*.css` | The 65 Lily themes, copied unmodified from upstream |
| Everything else in `src/` | Hand-authored |

Generated files are committed. Everything the built site needs lives inside
the site directory; nothing references `../` at runtime, because the
directory is published alone.

## Checks

- `pnpm test`: language router rules.
- `pnpm run check`: svelte-check, 0 errors.
- `pnpm run verify` (after build): 0 broken internal links or anchors.
- `pnpm run a11y` (after build): axe-core WCAG 2.2 AA, desktop and 390px,
  all 65 themes, 0 violations. `PW_CHANNEL=chrome` uses the installed Chrome.

## Dependencies

- `typescript` stays on 6.x; SvelteKit 3 needs TypeScript's JS API.
- `@lilydesignsystem/*` packages track latest. Refresh `static/themes/` after
  upgrading them.

## Publishing

```sh
git subtree push --prefix=queue-theory.github.io \
  git@github.com:queue-theory/queue-theory.github.io.git main
```

The published repository's `.github/workflows/deploy.yml` builds and deploys
to GitHub Pages on every push to `main` (Settings → Pages → Source: GitHub
Actions).
